# Comprehensive Build & Target Guide: Pico 2 W, Linux SITL & Linux SBC/FPGA

> [!IMPORTANT]
> **UNIFIED BUILD SPECIFICATION**
> `inav-abstractx` compiles into three primary target deliverables from the same source tree:
> 1. **Raspberry Pi Pico 2 / Pico 2 W** (`inav_abstractx_pico2w.uf2` - Bare-metal dual-core RP2350).
> 2. **Linux Desktop SITL / HIL** (`inav_abstractx_sitl` - Software-in-the-Loop simulation with TCP 5760).
> 3. **Linux Quad-Core SBC + FPGA** (`inav_linux_sbc` - PREEMPT_RT companion computer over PCIe TLP bus).

---

## 1. Target 1: Raspberry Pi Pico 2 & Pico 2 W (RP2350 Bare-Metal)

### Build Prerequisites
* `cmake` (>= 3.20)
* Toolchain and SDK dependencies are **automatically downloaded and managed via CMake FetchContent** (Pico SDK v2.1.1 and xPack ARM GCC toolchain).

### Step-by-Step Compilation:
```bash
cd /home/tcmichals/ssdData/projects/home/inav

# 1. Configure CMake with Pico 2 W target (FetchContent handles SDK offline):
cmake -B build_pico2w -DPICO_BOARD=pico2_w -DCMAKE_BUILD_TYPE=Release

# 2. Compile UF2 binary:
cmake --build build_pico2w -j$(nproc)
```

### Output Artifacts:
* **`build_pico2w/inav_abstractx_pico2w.uf2`**: Ready to flash to Pico 2 W.
* `build_pico2w/inav_abstractx_pico2w.elf`: Debug ELF symbol file.

### Flashing the Pico 2 W:
1. Hold the white **BOOTSEL** button on the Pico 2 W while plugging into USB.
2. The board appears as a mass-storage drive `RPI-RP2`.
3. Copy `build_pico2w/inav_abstractx_pico2w.uf2` to the drive (or run `picotool load -f build_pico2w/inav_abstractx_pico2w.uf2`).
4. The board reboots automatically into the flight controller.

### Connecting to iNav Configurator:
1. Connect your PC/tablet to the Wi-Fi AP generated by the Pico 2 W: **SSID: `inav-pico2w`** (Password: `inav1234`).
2. Open **iNav Configurator**.
3. Change connection type from *Serial* to **TCP**.
4. Enter IP: **`192.168.4.1`**, Port: **`5760`**, and click **Connect**.

## 3. Target 3: Linux Quad-Core SBC + FPGA PCIe Flight System

Targeted for **Raspberry Pi CM4 / Nvidia Jetson / Rockchip RK3588 / NXP i.MX8** paired with an FPGA over PCIe Gen2/Gen3 x1.

### Linux PREEMPT_RT Kernel Tuning (Host SBC):
To ensure zero latency spikes in the 16 kHz flight loop:
1. Add CPU isolation flags to `/boot/cmdline.txt` or GRUB:
   ```text
   isolcpus=3 nohz_full=3 rcu_nocbs=3
   ```
2. Lock process memory and assign real-time capabilities to the binary:
   ```bash
   sudo setcap cap_sys_nice,cap_ipc_lock+ep ./build/inav_linux_sbc
   ```

### Step-by-Step Compilation:
```bash
cd /home/tcmichals/ssdData/projects/home/inav

# 1. Configure CMake Release build for Linux SBC:
cmake -B build_sbc -DCMAKE_BUILD_TYPE=Release

# 2. Build Linux SBC executable:
cmake --build build_sbc --target inav_linux_sbc -j$(nproc)
```

### Executing the Real-Time Flight Process:
```bash
# Run with Core 3 isolation and SCHED_FIFO 99 real-time priority:
./build_sbc/inav_linux_sbc
```

### Threading & Hardware Resource Allocation:
* **CPU Core 3 (`SCHED_FIFO 99`)**: 16 kHz Flight Coroutine (`mlockall` active, 0 page faults).
* **CPU Core 2**: PCIe BAR Ring polling & MSI-X hardware IRQ reactor.
* **CPU Core 1**: Vision AI / SLAM / HD Video Pipeline.
* **CPU Core 0**: Linux OS, Wi-Fi/LTE, and Boost.Asio TCP Port 5760 Configurator Server.

### Connecting iNav Configurator over Network:
1. Connect PC to the same Wi-Fi / LAN network as the SBC.
2. In **iNav Configurator**, choose **TCP**.
3. Enter the SBC IP (e.g. `192.168.1.150`), Port: `5760`, and click **Connect**.
